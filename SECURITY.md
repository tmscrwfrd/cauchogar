# Política de seguridad

## Reportar una vulnerabilidad

Si encontrás una vulnerabilidad de seguridad en CauchoHogar, **no la publiques como issue ni en un PR público**.

Reportala de forma privada con el flujo de GitHub:

1. Entrá a la pestaña **Security** del repositorio.
2. Hacé click en **Report a vulnerability** (Private vulnerability reporting).
3. Describí el problema con el mayor detalle posible: pasos para reproducir, impacto y, si podés, una propuesta de mitigación.

Vamos a confirmar la recepción y te mantendremos al tanto del avance y de la resolución.

## Alcance

CauchoHogar es un sitio estático (landing institucional) publicado con GitHub Pages. Nos interesan especialmente:

- XSS u otras inyecciones en el contenido servido.
- Exposición de datos sensibles.
- Problemas en la configuración de despliegue (GitHub Pages / CI / GitHub Actions).

Reportes fuera de alcance (p. ej. resultados automáticos sin impacto demostrable) pueden cerrarse sin acción.

Gracias por ayudarnos a mantener el proyecto seguro.
